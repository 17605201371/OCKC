# 页面易用性优化（本地，未发布）

基于 `5dc16ca71ea4e4c7c8bdee6ccd22e2afb09d3ca5` 的页面审查结果，优先修复实际的操作可达性问题，不新增业务状态或数据库迁移。

## 本轮修改

1. **桌面长文档操作栏**：在 1000px 及以上宽度固定在全局顶栏之下，保存、提交、评分草稿、下一份及手动发布入口继续使用原有处理函数和保护条件。ResizeObserver 测量工具栏换行后的真实高度，侧栏同步避让；卸载断开观察器。不代表整站移动端工作台已完成适配。
2. **编辑器原生弹窗**：公式、图片、链接及帮助弹窗统一采用头/滚动内容/底部操作三段布局；外层不滚动，取消/确认留在可见范围。公式在 1280×720、1440×900、390×844 验证。保留原生 dialog、焦点约束、Escape 和取消不修改正文的规则。
3. **评分填写进度**：显示已填写指标数，支持展开并定位下一项未填写指标。有效的 0 分计入；N/A 必须填写理由；待核验不计入。只是辅助填写，不代替正式评价校验，不自动评分、提交或发布。总评、核验、并发/草稿冲突等既有规则保持不变。
4. **批改队列**：作业/作者/排序保持直接可见；版本范围、评分草稿、证据状态可收起，按钮标注生效条件数，收起不清除条件。顶部新增分页入口，底部仍保留原有入口；不改服务端分页、范围统计和请求序列保护。
5. **图片工具栏**：移到独立行，不再盖住图中数据；只在可编辑模式显示，图注、来源、稳定 blockId、证据与撤销功能保持不变。
6. **辅助文字**：质量说明、反馈版本信息、引用、隐私提示与编辑器状态等关键小字提高至 12px，继续使用语义主题色。
7. **报告时间与版本**：报告界面显示北京时间（明确 UTC+8），原始精度保留在 `time` 的 datetime/title 和 JSON 数据中；长量规编号不在中间断行。独立 HTML/JSON 导出协议及原始数据不变。
8. **公式流程提示**：解释“填写结构并应用 → 检查 LaTeX 预览后确认”的两步操作，避免误以为预览已写入正文。

## 未在本轮更改

- 暂不引入可拖动宽度的评分面板；优先保持文档宽度与键盘焦点稳定。
- 原有模板替换、正式提交/发布等原生确认继续保留，不借本轮布局优化削弱确认语义。
- 不改变请求失败时隐藏旧队列的行为，不让过期结果继续可操作。
- 实现和验收阶段未提交 GitHub、未部署线上环境。随后已按用户授权提供独立临时演示预览，并将源码提交功能分支；仍不合并主分支、不进行长期正式部署。最新状态见 GITHUB-HANDOFF.md。
