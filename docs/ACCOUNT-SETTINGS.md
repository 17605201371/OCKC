# 个人账号设置（仅本地开发）

## 范围

本轮实现本人显示名称更新、安全改密、旧会话失效与草稿保护。不包括注册、邀请开通账号、邮箱变更、邮件找回、SSO/MFA、账号停用或管理员重置密码。课程成员管理仍不能创建平台账号或授予任课教师身份。

- 入口：侧栏底部「账号设置」；收起侧栏后仍可使用。
- 原生模态框、键盘 Escape、焦点返回、深浅色语义配色、390px 适配。
- 打开前先保存写作或评分草稿；保存失败、冲突或上传未完成时阻止打开。
- 请求失败可重试；不自动重放改密请求。

## 接口

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/api/account` | 本人 id、email、display_name、profile_revision、password_changed_at；no-store |
| PUT | `/api/account/profile` | `{displayName, revision}`；只修改本人显示名称；过期 revision 返回 409 |
| PUT | `/api/account/password` | `{currentPassword, newPassword, confirmation}`；必须使用真实账号密码登录会话 |

所有接口要求登录；写操作需要 CSRF。身份和目标来自已认证主体，不接受用户 id、邮箱或角色覆盖；未知 JSON 字段会被拒绝。响应不包含密码哈希、凭据版本、错误计数或锁定时间。

## 显示名称

- 去除首尾空白，1–40 个 Unicode 码点，拒绝控制字符及格式控制字符。
- 独立的 profile_revision 防止旧窗口静默覆盖；冲突时用户可刷新资料并保留输入，核对后再次保存。
- 更新不会改写已提交正文、课程身份或作品历史；界面查询到的作者显示名称可随账号资料变化。

## 密码与会话

- 验证当前密码；新密码不是纯空白，至少 12 个 Unicode 码点，最多 72 个 UTF-8 字节，拒绝控制字符。
- 不得与当前密码相同，确认必须一致。保留原始密码内容，不 trim、截断或做隐式规范化。
- BCrypt cost 12。72 字节上限显式验证，避免 BCrypt 截断产生密码别名。
- app_user 行锁串行化修改；认证时同一行读取密码哈希和 credential_version。认证主体保留非秘密版本，凭据清除不影响版本。
- 改密事务同时更新哈希、credential_version、password_changed_at、审计记录并重置失败计数；成功后才注销本次会话。
- 其他旧会话在下一次受保护 API 请求时由 CredentialVersionFilter 拒绝并注销（401）。不声称取消已经开始执行的请求，也不包含服务端会话清单或主动设备推送。
- 当前密码验证失败次数保存在数据库中；第 5 次失败后锁定 15 分钟。失败结果以返回值完成事务，避免抛出异常回滚计数；429 带 Retry-After。
- 错误响应与审计不记录密码或哈希。前端不写入任何密码到 localStorage，提交完成/失败或关闭时清空输入；保留标准浏览器密码管理器 autocomplete 支持。

## 草稿安全

401 通过统一会话过期事件收起旧课程数据并显示重新登录提示；旧请求不能在新登录后再次注销新会话。写作备份按账号/作品隔离保留；评分草稿暂停自动保存，保留本机备份。重新登录原账号后，原作品提供显式恢复，不自动覆盖服务端正文。若浏览器存储不可用，则保留内存中的写作/评分快照，先提供下载备份，再允许重新登录切换工作区；评分导出不等于自动重新导入。

## 数据库迁移与边界

`V9__account_settings.sql` 为 app_user 增加资料版本、凭据版本、改密时间、失败计数和锁定截止时间，不修改已有作品数据。已在隔离 H2/MySQL 兼容模式验证；生产 MySQL 迁移、真实部署账号恢复和集中式登录限流仍需上线前验收。

目前会话版本在每次受保护请求查询数据库，优先确保撤销生效；没有进程内版本缓存。现有登录入口的 IP 限流仍是单实例实现，不等于分布式防护。改密锁定不阻止正确凭据的普通登录，也不重置其他账号的会话。

## 验证

- AccountSettingsTest：19 项，覆盖权限、CSRF、过量字段拒绝、资料冲突、Unicode、字节上限、锁定、真实登录会话、跨账号隔离、草稿保持、审计。
- accounts-e2e.mjs：18 组浏览器断言、7 张截图；包含读取失败重试、多窗口冲突、深色/窄屏、错误当前密码、未保存草稿阻止进入、旧会话失效、重新登录和恢复提示。
- 仅允许 loopback E2E_BASE_URL；密码从环境提供，不在脚本中嵌入部署凭据。

本轮不发布、不部署、不更新在线数据库或在线预览。
