## 关键覆盖

1. 学生只导出本人；公开同伴作品不因此开放其私有报告。非成员/移出课程/伪造作者筛选拒绝；教师、助教按本课既有权限只读。
2. CSV 包含全部匹配页，25 篇实际应用记录验证；状态过滤与概览范围分开标注。2000 篇边界及超限真实后端验证；不静默截断。
3. 区分最新提交与最近已评分版本；无评分为空，真实零分保持零；复评只显示该提交当前生效评价及修订号，不伪造新提交。
4. 报告包含所有范围内提交元数据、正式评价、反馈和动作，不暴露正文、未提交草稿、邮箱或教师私有评分草稿。回应/采纳/忽略不自动解决；已下载快照不随后续处理改变。
5. 原始提交量规标记与历史缺失状态保持真实；不用新锚点改写旧记录。
6. 中文、换行、引号和公式前缀 CSV 处理；HTML 对全部动态字段文本转义，限制 CSP，无脚本、图片、活动链接或联网资源；真实恶意标题仅显示文本。
7. 503 重试、关闭取消、迟到响应、旧登录代次、401 会话恢复；错误清空报告并隐藏下载，避免下载错范围旧内容。
8. 深色主题、390px/1280px 无横向溢出，键盘 Escape 返回原按钮；嵌套轨迹详情关闭后焦点正确。

## 测试边界

浏览器 503/延迟和 422 提示明确使用本地响应夹具；上限 2000/200/500/1500 的实际拒绝由后端 H2 测试覆盖。其余记录创建、私有评分草稿、反馈处理和新提交使用真实隔离 API。可打印 HTML 实际在本地打开并验证打印媒体，无脚本执行、无外部请求；没有生成服务器 PDF 或验证各家电子表格客户端。未做生产压力、分布式一致性或真实学生数据验收。

详细检查项见同目录 `VALIDATION-REPORTS-LOCAL.json`，功能与接口见 `PROGRESS-REPORTS.md`。源码归档不含测试运行数据、密码、上传文件、node_modules、构建产物或日志。
