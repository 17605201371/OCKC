# 首页四维质量横线展示

科学性、准确性、完整性、逻辑性各占一行，左侧名称，中间 5px 横线，右侧一位小数的正式分数。浅深色继续使用语义变量；真实零分保持 0.0，缺失或无效分数显示 —，不填充进度条。教师概览没有作品正式分数时同样显示 —，不伪造班级平均分。

仅调整首页四维质量卡片，不改评分、数据库、编辑器四维指标及上一轮操作栏/弹窗优化。支持桌面视口 1280px 及以上；390px 首页侧栏原本隐藏，本轮不扩大移动端范围。进度条提供维度名称、0–100 范围与当前值，无评分时提供独立的无评分说明。

构建与当前隔离回归实际通过：dimensions 5 组，polish 9 组，theme 10 组。dimensions 检查浅深色、1440/1280 布局、真实分数、拦截夹具中的 0/100/空值、待评作品与教师只读概览。详细结果见 VALIDATION-DIMENSION-LINES-LOCAL.json。后端本轮未更改，未将历史后端测试冒充重跑。

已更新临时演示预览；用户随后授权将最新源码提交 GitHub 功能分支，未合并 main，未进行长期正式部署。验收 JSON 中的 githubPushed=false 记录的是验收当时的状态，最新提交状态见 GITHUB-HANDOFF.md。演示数据库与真实课程数据隔离，账号说明不进入源码包。
