# PC 界面更新记录

## 视觉基线

根据用户提供的 HTML 原型重做 Vue 界面，而非只替换主色。采用暖灰侧栏、56px 紧凑顶栏、白色内容区、克制的靛紫操作色、细边框和清晰的文字层级。PC 验证宽度为 1440px 与 1280px，移动端不在本次范围。

- 首页：当前任务、下一步反馈、进度与质量分；真实待办和近期作业，课程与四维质量位于辅助栏。
- 创作与阅读：收起导航为图标栏，正文优先；可展开段落大纲，可收起反馈栏进入专注编辑。
- 教师评审：固定版本正文与四维评分分栏，评分维度可折叠，保留 11 项计分和原有质量门槛。
- 其他页面：统一作业、批改、社区、证据、量规和弹窗；增加实际可用的搜索、筛选、键盘关闭和主题切换。

## 与原型的必要差异

使用实际 API 数据，不复制原型中的虚构待办数量、课程、协作者和学习成效。仍是四维 11 项，而不是原型示例中的五维。未实现的成长档案、通知、图片上传或 AI 功能不展示为可用入口。正文中的图表不会为了截图好看而伪造成已上传材料。

## 验证

- Vue / TypeScript 生产构建通过。
- Spring Boot `mvn -B verify`：20 项测试通过。
- HTTP 真实流程：29 项断言通过。
- Chromium 界面流程：19 个页面或状态截图；登录、自动保存、不可变 v2 提交、反馈定位、教师队列、量规、阅读、证据、搜索、大纲、专注编辑、空状态、深色和 1280px 检查通过。未发现页面脚本异常和页面横向溢出。
- 已逐张检查界面截图；最终首页另以独立 HTML 渲染复核。临时预览不是生产部署，也不保证沙箱空闲后继续运行。

测试均使用独立演示数据库，不代表实际教学成效或生产安全验收。
