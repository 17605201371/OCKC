## 新增验证重点

- 教师编辑指标说明和锚点，学生不可读草稿；启用后版本只读。
- 草稿乐观锁、课程目录修订号、跨课程与非教师写入限制、CSRF、固定代码集合与输入长度。
- 保存失败后本机备份、显式恢复、多窗口冲突保留输入、未保存导航保护、版本选择器不错误跳转。
- 作业显式绑定、课程默认变化不影响旧任务、真实富文本提交保存快照、阅读/评分使用绑定锚点。
- 从快照入口看历史标准；课程导航明确退出快照模式，不滞留旧快照。
- 默认恢复基础版、教师操作历史、后续默认版本切换不改变已存快照。
- 复评和幂等请求保留原快照；未知历史版本或损坏快照拒绝读取/评分。
- 深色桌面、1280px 与 390px 布局；无横向溢出；键盘激活。
- 教师会话过期且 localStorage 不可写时，仍保留量规输入于内存；重新登录前要求下载 JSON 备份。
