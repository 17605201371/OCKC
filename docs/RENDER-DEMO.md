# PC 演示站：在你自己的浏览器里部署

入口：https://render.com/deploy?repo=https://github.com/17605201371/OCKC

这是一键导入配置入口，不是已上线的网站。需要仓库拥有者登录 Render 并确认创建资源。不要把 Render/GitHub 密码或 token 发到聊天里。

## 操作

1. 在你自己的浏览器打开入口，登录或注册 Render。可选择 GitHub；如请求安装 GitHub App，尽量仅授权 OCKC 仓库。
2. 进入 Blueprint 创建页；确认仓库为 `17605201371/OCKC`、分支为 `main`。
3. 为 `DEMO_PASSWORD` 填写自己保存的至少 16 位随机密码。四个演示账号初始共用此密码；不要把它提交到 GitHub。
4. 确认服务使用 Free 计划。若显示收费、要求升级或添加付费资源，先停止，不要自动确认。
5. 点击页面的部署/创建按钮（界面名称可能变化），等待构建完成。当前环境没有 Docker，因此此配置仍需本次线上构建实际验证；不要将配置文件存在视为部署成功。
6. 在服务页找到 Render 分配的 HTTPS 地址。状态应为 Live；先访问登录页，再用下列账号验证。

| 邮箱 | 角色 |
| --- | --- |
| teacher@example.test | 教师 |
| student@example.test | 学生 |
| peer@example.test | 同班学生 |
| outsider@example.test | 另一门课程学生 |

密码为第 3 步设置的值。首次默认示例不是实际教学记录。登录成功后再进行学生修订、教师批改与发布核验。

## 限制

- 只提供 PC 浏览器体验，不用于真实教学与正式数据。
- Free 的文件系统不持久，休眠/重启/重新部署后，本地数据库和演示操作可能丢失；下次启动将重新生成演示数据。
- 服务可能休眠，首次访问需要等待启动；免费额度/政策以 Render 页面为准。
- 配置不创建付费数据库、持久磁盘或自定义域名，自动部署关闭，避免每次代码更新都重置演示。
- HTTPS 会话 cookie 已启用 Secure；数据库密码由平台生成；演示登录密码仅在平台安全环境变量保存。
- 当前环境不具备容器运行时，仍需确认 Docker 构建、内存额度和线上健康检查实际成功。
- 若构建失败，只提供脱敏的错误日志/截图，不要提供环境变量的值。
