# 课程成员管理（开发版）

## 入口与范围

任课教师侧栏「课程成员」，课程作业页也有「成员管理」入口。沿用已有蓝灰/紫色视觉变量、列表与原生对话框，支持 PC 1280px 及以上和深色模式。

- 列表按教师、助教、学生排序，支持姓名/邮箱搜索、身份筛选、每页 20 人、身份人数统计。
- 只添加已经存在的平台账号；邮箱不区分大小写，必须唯一匹配。不存在的邮箱不会注册账号、设置密码或发送邀请邮件。
- 只允许学生与助教之间调整。助教可查看本课评审材料，但不能正式发分、管理成员或读取教师私有评分草稿。原作者改为助教后也不能继续学生作答、保存、提交或上传图片。
- 所有教师行受保护；不支持调整/移出教师、操作本人、授予教师权限或课程所有权交接。
- 课程名单含邮箱，仅本课任课教师可见，不向学生、助教或其他课程账号开放。

## 变更、安全与数据保留

添加、身份调整、移出均进入成员操作记录；身份调整和移出必须填写原因。教师可查看最近 100 条的操作者、目标账号、时间、前后身份及原因。原因不复制到成员通知。

写操作持有课程行锁，递增 `roster_revision`。新界面使用打开对话框时的 revision；名单被另一窗口修改时返回 409，保留本地输入，不静默覆盖。用户明确确认后才关闭旧输入并刷新名单。旧添加账号 API 可省略 revision 以兼容既有调用，但不能覆盖已存在成员的身份；新身份调整与移出入口必须提供非负 revision。

移出只删除课程成员关系，**不删除账号、作品、提交、评价、核验、媒体或历史操作**。服务端对后续请求重新验证课程权限。已在授权有效时进入处理的并发请求不承诺取消/回滚；这不是全局实时撤销机制。

重新添加同一个账号会恢复它对本课历史数据的访问，也可能重新看到其仍符合接收条件的历史站内消息。添加和身份调整产生站内身份通知；移出后不再有本课消息访问权限，因此不发送其无法读取的移出通知。没有邮件推送。

## 已打开页面与本机备份

页面每 30 秒及重新获得窗口焦点时校验当前课程成员关系和身份；变化后收起当前课程内容，引导重新进入可访问课程。已经下载或看过的信息无法通过这个动作追回。断网无法完成策略刷新时显示错误，最终写权限仍由服务器验证。

若当前是作者编辑器，收起前将正文、标题、证据与 revision 留作本机备份，可主动下载 JSON；不向其他服务发送正文。原账号重新加入后，可进入原作品手动「恢复到编辑器」，核对后保存。备份只按账号/作品键隔离，localStorage 不是加密保险箱；共享电脑使用后需要清理站点数据。退出登录清除内存中的下载备份，不自动删除旧本地备份。

该 JSON 下载是应急保留文件，目前不提供任意 JSON 文件导入；站点数据清空或浏览器存储不可用时不能保证自动恢复。教师私有评分草稿仍使用既有独立恢复机制。

## API

见 [API.md](API.md) 中成员管理表。所有写请求需要会话与 CSRF；身份检查来自数据库当前成员关系而非仅前端菜单。V6 迁移新增名单 revision 和变更表；旧成员不虚构补录操作原因。

## 验证与边界

新增 20 项后端测试，总计 105 项；新增 12 项浏览器检查、8 张状态截图。覆盖查询/隐私、教师保护、学生/助教/跨课/CSRF 拒绝、重复与并发、移出保留历史、重新加入、正在编辑时权限变化、本机下载与恢复、过期保存返回不能重新打开页面。脚本 `scripts/members-e2e.mjs` **只接受 localhost 的独立演示库**，会调整测试账号成员关系，不可运行在真实课程上。

当前没有批量导入、邮箱邀请、账号创建/禁用、密码重置、教师交接、回收本机已缓存信息或实时 WebSocket 撤权。H2 测试通过不代表 MySQL/生产并发、安全与灾备验收完成。AI 仍未接入模型，成员管理不会改变原有教师作业级 AI 开关。
