# 当前版本收尾状态与后续范围

## 结论

本交付是 **v0.1.0 第一阶段 PC 开发基线的本地收尾**，不是 16 周整体建设完成、生产就绪或在线发布。用户要求“暂不发布”，因此没有远程推送、部署或在线数据变更。

本轮四项收尾：
1. 从上次完整源码归档恢复，修改前核对 153 个源文件的 SHA-256；交付附更新后的完整源码清单。
2. 只读配置预检与统一构建验证入口，清除旧静态资源；修复登录完成但工作区未就绪时导航被重置的竞态，加载失败可重新登录重试。
3. Linux H2 停机备份、完整性核验和不覆盖恢复工具；用真实迁移数据库重启验证，运行库锁拒绝、图片与已有记录对比通过。
4. 全量本地回归、明确边界和完整源码交付。准确执行次数与结果见 [最终本地验收](VALIDATION-FINAL-LOCAL.md)。

## 尚未完成：七类后续建设

这七类是独立建设范围，**不能算成七个小 bug，也不能因本轮收尾而标为完成**：

1. **真实 AI 服务**：模型接入、授权与脱敏、调用治理、人工确认与质量验证。现有 AI 入口仅策略/状态，不发学生正文、不模拟模型评分。
2. **外部内容与生产媒体**：对象存储、配额/回收、授权教材自动比对、可视化公式输入。
3. **完整移动端**：全工作流触控/小屏交互与系统级验收；部分 390px 专项通过不等于全端完成。
4. **协作与题库**：实时多人编辑、小组分工/协商、分步习题与题库。
5. **深入分析与自定义评价**：自定义权重/指标、跨课程量规共享、专家校准、深度班级分析、异步大批导出、XLSX/服务器 PDF。
6. **身份与管理平台**：注册/邀请/密码找回、完整后台、SSO/MFA、生产分布式会话。
7. **生产运行认证**：MySQL/对象存储备份、加密/异地轮换、告警监控、合规审查、安全审计及 200 会话压力测试。已有 Linux H2 停机恢复不能替代这些。

下一次若继续建设，应明确选择上述范围与验收标准，而不是将其无限混入“当前版本收尾”。任何上线仍需另行授权。
