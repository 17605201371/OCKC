## 主要验收内容

- 新队列权限、no-store、20 行服务端分页、稳定时间相同排序、无重复跨页、超出页码回落、空范围与文字通配符转义。
- 统计按真实提交版本，不把草稿当正式评分；零分仍是有效评价。范围概览与状态/证据/草稿过滤后的列表数量分别展示。
- 每篇最新提交和全部历史范围分别统计，并明确提示隐藏旧版不等于完成旧版评审。
- 教师仅看本人草稿标记，不返回草稿内容；其他教师、学生、助教、移出课程后的权限边界。助教即使曾留下教师草稿也不返回标记，兼容旧端点同步保护。
- 首页最多 6 条摘录，但待评总数仍按全课真实记录计算；局部搜索不把全课导航徽标变成筛选数量。
- 打开冻结版本后返回，保留筛选和页码；常规权限刷新不擦除同一上下文，切换角色/课程/账号则清空。
- 连续评审先保存当前私有评分草稿；故障夹具制造 503 时保持原分数与总评并阻止离开，重试后真实草稿保存成功，但不自动创建正式评价。
- 下一份按当前范围实时挑选未评分、非当前提交，已被评价的候选不再返回；不写审计、不领取锁，不标记完成。没有其他候选时留在原页说明原因。
- 真实同伴互相冲突的证据核验反映到原提交队列；不以核验结果替代正式评分。
- 错误清空旧行、可显式重试，搜索乱序响应不可覆盖新范围；键盘 Enter 打开准确版本；1280px 与 390px 深色布局无横向溢出。

## 修复与测试边界

验收发现阅读/评分页返回链接被旧编辑器通用样式隐藏，已用限定选择器修复并完成真实返回页码测试。富文本回归原先默认点击队列第一条；新默认最早优先会读到较旧版本，因此测试改为明确定位林同学 v2，不减少图片、公式、表格或冻结版本断言。

浏览器分页数据通过真实 API 创建 25 份新提交及对应作业，未绕过“上一版须先评审才能继续提交”的正常约束。503/延迟/乱序明确使用本地故障响应夹具；历史状态和完整边界由 H2 服务测试覆盖。

本轮不做生产压力、多人任务锁、批量发布、教师绩效排名或全流程移动端认证。旧回归中正式评价/课程内展示的操作只发生在独立可丢弃测试库，不是发布在线版本。新工作台本身不自动发布任何评价或作品。

全部检查项见 `VALIDATION-REVIEW-LOCAL.json`。功能口径与接口见 `REVIEW-WORKBENCH.md`。
