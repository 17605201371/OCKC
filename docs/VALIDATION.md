## 复验

先按照 README 初始化**独立演示数据库**并启动应用。以下脚本会修改演示数据，不可指向真实课程。

```bash
# 使用初始化该演示数据库时设置的密码；不要写入 Git。
export E2E_PASSWORD="$DEMO_PASSWORD"
node scripts/ui-smoke.mjs
python3 scripts/api-e2e.py
```

UI 脚本需要新初始化的默认演示数据；第二次运行请另设 `DATABASE_URL` 使用新的演示库，不要为重跑测试删除真实数据库。脚本启动前按 README 安装 Playwright Chromium；或设置 `CHROMIUM_PATH` 指向本机可执行文件。
