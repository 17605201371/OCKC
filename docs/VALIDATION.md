## 未验证与边界

- 仅 PC；移动端不属于本期开发和验收范围。
- 本机没有 Docker/MySQL：Compose 和 MySQL 驱动/迁移配置已提供，但尚未实际跑通 MySQL 集成验收。
- 未执行 200 会话压测、真实备份恢复、生产跨浏览器矩阵、渗透测试、真实学生数据或校方合规审查。
- AI、对象存储/媒体回收、量规编辑、深度统计报告、SSO 与完整账号管理尚未实现；当前已支持图片上传与基础轨迹/进展。
- CI 模板位于 `docs/ci-template.yml`，受工作流写入权限限制，暂未启用；仅表示已提供自动化流程；本记录不等同于 GitHub Actions 已运行成功。
- 编辑器已按需加载；初始主 JS 约 163KB、编辑器与公式约 734KB（均为未压缩大小），编辑器仍有体积提示，不影响构建成功。

结论：可以作为本地运行、代码评审与下一阶段开发的基线；不能直接宣称可面向真实学生生产上线。
