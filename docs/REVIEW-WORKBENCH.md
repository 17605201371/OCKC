# 批改中心：分页筛选与连续评审（本地待发布）

## 本轮完成

- 服务端每页 20 个提交版本；按作业、作者、关键词、评价状态、本人评分草稿、证据状态和版本范围筛选。关键词匹配冻结提交标题、当前作者显示名及作业名，`%`、`_`、`!` 作为文字，不是用户可注入的通配 SQL。
- 最早提交、最近提交、证据争议优先三种排序，均以提交编号兜底，避免相同时间戳时跨页重复。页码超出当前结果后自动落到最后一页；更换筛选回到第 1 页。
- 概览计算版本总数、待正式评价、已正式评价、本人草稿及含争议证据的提交数量。概览遵循关键词/作业/作者/版本范围，不随评价/草稿/证据标签或分页改变。不是学生人数、成绩排名或课程完成率。
- 每篇作品最新提交是可选筛选，默认仍展示全部真实提交。最新视图明确提醒旧版可能仍待评审，不自动评价、删除或合并历史版本。
- 行中展示本人草稿是否基于过期评价、待核验及争议证据数量；未评分不显示成零分，已有草稿不当成已评价。
- 返回批改队列保留本次会话内筛选和页码；同课程的常规权限刷新不清空条件。切换课程、账号或角色后清空上下文，不跨身份保存。没有把队列筛选写入 localStorage。
- 修复阅读/评分页返回按钮被旧编辑器通用 CSS 隐藏的问题。

## 下一份待评审

从队列进入评审后，“下一份待评审”沿用进入时的关键词、作业、作者、版本、草稿、证据范围和排序，**只选择另一份当前没有正式评价的提交**，不沿用页码；“已评价”标签不会使它打开另一个已评版本。未从队列进入时，使用默认全课范围、最早优先。

切换前通过既有评分草稿保存保护。保存失败时停留在当前提交，分数和总评输入保留，不标记完成、不发布评价。服务端重新读取当前评价状态，跳过已评价和当前提交；没有其他匹配记录时留在原页并说明，可返回队列调整范围。

这是“下一份候选”，不是排他锁、领取任务或自动评审。另一位教师可以同时打开同一版本；最终保存和发布仍使用原有草稿修订号与正式评价版本冲突检查。连续点击受界面进行中状态保护；迟到响应不得跨课程/账号应用。

## 首页与权限

首页不再请求全量旧队列，只读取最多 6 条待评优先摘录和全课准确统计；导航徽标和首页待评数量不受摘录长度及批改中心的局部筛选影响。首页文案明确是摘录，完整记录在批改中心读取。

仅当前课程教师/助教可读取。学生、其他课程账号和被移出课程账号拒绝。历史作者提交保留并在作者选项标记历史成员，不自动删除作品。

私有评分草稿仅任课教师本人可见，队列不返回任何草稿正文、总评、评分明细、理由或其他教师草稿标记。助教不展示本人草稿筛选，也不能伪造参数读取草稿标记；即使该账号历史上留下过教师草稿，降为助教后也不返回其草稿元数据。兼容旧队列接口也加上同样保护。助教打开的评审表单继续只读，不获得评分发布能力。

## API

均为 GET、`Cache-Control: no-store`，不写数据库、不领取任务，无新增迁移。

- `/api/courses/{cid}/review-workbench`
  - `q` 默认空、最长 80；`assignmentId` / `authorId` 非负、0=全部。
  - `state=ALL|PENDING|GRADED`；`drafts=ALL|MINE|NONE`（助教只能 ALL）。
  - `evidence=ALL|PENDING|DISPUTED`；`versions=ALL|LATEST`。
  - `sort=oldest|recent|evidence`；`page` 1–100000。
  - 返回 items、summary、total、规范化 page、pageSize=20、teacher、当前课程 assignments/authors。
- `/api/courses/{cid}/review-workbench/dashboard`：全课 summary 和最多 6 条摘录，不随队列筛选变化。
- `/api/courses/{cid}/review-workbench/next`：同范围参数，额外 `excludeId`；忽略列表页码及评价标签，强制待评，返回 item 或 null 与剩余候选数量。非本课 excludeId 拒绝。
- 原 `/review-queue` 列表接口保留兼容，但新版页面/首页不再使用全量载入。

非法参数 400，无权限 403，错误当前提交 404。404/403/服务器失败不视作“队列完成”。页面读取失败清空旧行并显示重试；乱序搜索响应和卸载后的响应均丢弃。

## 已知边界

不批量发布评分，不引入任务分配/教师工作量排名/超时锁，不以证据核验直接替代评分。筛选与位置在当前登录的内存中保留，浏览器完整刷新后使用默认范围。未进行生产规模查询/200 会话压力验收；未宣称全流程移动端认证。深色、390px/1280px 队列专项覆盖不代表编辑器全部移动交互完成。

仍未发布、部署、推送或变更在线数据库。
