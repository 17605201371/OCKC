# 学习 / 教学进展报告导出（本地待发布）

本功能只在本地开发和隔离测试中启用，未部署或修改在线数据库。报告下载不发布作品、不发送邮件，也不创建公开链接。

## 使用入口

- 「学习轨迹 / 教学进展」顶部 **导出当前筛选 CSV**：确认课程、作业、作者、关键词和状态范围后，下载全部匹配页，不是只导出当前显示的 20 张卡片。
- 作品卡片「完整版本与反馈」→ **生成作品报告**：生成完整版本和教师反馈的只读预览；可下载同一快照的 **JSON** 或 **可打印 HTML**。
- HTML 不依赖联网或脚本，可以在用户自己的浏览器中打印、另存 PDF。本版不直接生成 PDF，也不包含完整作品正文或量规锚点，不可作为档案备份。

## 身份与隐私

- 学生仅能导出自己的作品和学习轨迹。即便能阅读同伴已发布作品，也不能导出同伴的私有轨迹报告。
- 教师和助教沿用既有课程进展只读权限，可导出本课程作品；不因此获得修改评价的权限。
- 每次生成重新校验当前课程成员身份；移出课程后新请求被拒绝。教师可保留查看课程历史作者的记录。
- 报告不含邮箱、密码、正文草稿 JSON、完整正文或教师私有评分草稿；显示名称使用生成报告时的当前名称。
- 文件包含个人学习记录与教师反馈，下载后需自行安全保存。权限变化不能收回已经下载到本机的文件；共享设备须清理下载内容。
- GET 响应标记 `Cache-Control: no-store`；CSV 使用固定 ASCII 附件文件名、`text/csv;charset=UTF-8` 和 `nosniff`。

## 统计与历史真实性

1. CSV 的**概览**遵循作业、作者、关键词范围，与进展页面一致，不随状态标签改变。**导出行**另遵循当前状态筛选；两个数量分别标明。
2. 最近质量均分按每篇作品最近一个已正式评分的提交等权计算，不是所有版本平均、课程总成绩、排名或成长率。
3. 最新提交版本与最近已评分版本分列。新版本待评时不会把旧分数冒充新版本成绩；未评分保持空白 / 未评分，不计为 0。真正的 0 分仍保留。
4. 每个提交只显示生成时当前生效的正式评价及其评价修订号；复评不新增提交版本。报告为生成时快照，已下载文件不会自动跟随后续复评变化。
5. 反馈含提交版本、原段落引用、指标、正文、解决状态和完整处理记录。回应、采纳、忽略均不自动表示解决；由教师确认。
6. 草稿标题、修订号只作为当前作品索引；每个提交行另保留冻结标题。修订号不代表提交次数，提交次数不能单独证明学习成效。
7. 量规来源标记：`SUBMISSION_SNAPSHOT` 为已保存提交快照；`BUILTIN_LEGACY` 仅显示已知旧基础规则，不追溯锚点；`UNAVAILABLE` 表示当时标准无法完整核对，不使用当前默认标准代替。报告可继续保留该版本的真实评价和反馈。

## 完整性与容量

本版同步生成，所有查询位于只读、可重复读事务内，报告不静默截断：

| 范围 | 上限 | 超限行为 |
|---|---:|---|
| 筛选 CSV 作品数 | 2000 篇 | 拒绝生成，要求缩小作业、作者、关键词范围 |
| 单作品提交版本 | 200 个 | 拒绝生成，提示课程维护人员处理 |
| 单作品反馈 | 500 条 | 同上 |
| 单作品反馈处理记录 | 1500 条 | 同上 |

CSV 有 UTF-8 BOM，所有单元格按 RFC 4180 引号转义。电子表格公式前缀（包括空白后 `= + - @`、制表符和换行前缀）加文本保护，不把引号本身当作公式防护。文本换行规范化为 LF，CSV 行使用 CRLF。

HTML 所有动态内容均作文本转义，没有脚本、外部图片、链接、表单或网络依赖，并设置限制性 CSP；固定打印样式与预览深色主题分离，避免打印黑底耗墨。JSON 保留结构化报告数据，不嵌入 HTML。

## 异常与生命周期

- 读取失败清空报告内容，成功重试前不显示下载按钮；CSV 失败显示服务器原因和重试入口。
- 关闭生成中的 CSV 会取消请求；关闭预览或离开课程后，迟到响应不会重新打开页面或触发下载。
- 文件请求使用和 JSON 请求相同的会话代次校验，身份切换后旧响应不允许下载。401 使用现有会话失效与草稿保护机制。
- 未预先保存导出副本到 localStorage，也不在服务器创建下载文件；下载由用户明确点击触发。
- 原生模态框支持 Escape，并将焦点返回触发按钮；深色、390px 和 1280px 布局纳入验收。

## API

- `GET /api/courses/{cid}/progress-export.csv?q=&assignmentId=0&authorId=0&state=ALL&sort=recent`
  - 参数与进展页面共享同一校验和 SQL 范围构建器；忽略页面位置，不读取 `page`。
  - 非法筛选 400；无权限 403；超限 422，不返回部分 CSV。
- `GET /api/progress-entries/{id}/report`
  - JSON schemaVersion 1；含 `generatedAt`、`entry`、`summary`、全部 `versions`、全部 `feedback`（每条附完整 `actions`）及使用说明。
  - 版本包括当前评价修订号、四维分数、教师总评、当时量规来源和证据状态计数；不含原始量规快照 JSON 或完整作品正文。

没有新增数据库迁移，使用已有 V1–V10 的真实提交、正式评价与反馈记录。尚未实现异步大批量导出、XLSX、服务器 PDF、全作品档案备份或生产数据治理审批。
