# 课程量规版本（本地待发布）

本轮未部署、未推送、未修改在线数据库。下述“启用”仅是应用内课程配置状态，不等于部署系统或发布学生作品。

## 使用路径

1. 教师进入「课程量规」，从基础量规或任一已启用版本复制为修订草稿。
2. 填写标题、总体说明、11 项指标的说明与四个评分区间锚点；保存仅教师可见。
3. 填写启用理由，启用版本并设为**新作业**的默认值。版本随后只读；调整须复制新草稿。
4. 创建作业时明确选择已启用版本。默认值变化不改绑已有作业，作业管理也不提供重新绑定。
5. 学生提交时保存完整量规快照。阅读和教师评分从该快照显示锚点，不从当前课程默认配置读取。
6. 可将先前启用的版本或基础版重新设为默认；启用、切换理由与操作者保留在教师专属记录中。

## 本轮配置边界

- 仍为科学性 S、准确性 A、完整性 C、逻辑性 L **各 25%**。
- 11 项指标代码、名称和评分算法固定；不支持任意权重、增删维度或指标。
- 可以调整标题、说明、单项判分描述及四区间锚点；锚点是教师判分参考，不自动生成成绩。
- 基础量规的新增锚点是通用示例，不是经过学科专家校准的评分标准；具体课堂应由教师配置并审核。
- 0–100 分、最多两位小数；N/A 必须写理由且不计零分；每维至少一项有效分；待核验不正式发分；已确认严重缺陷封顶 89。原有计算规则不变。
- 每门课程最多 100 个自定义版本。列表有界；最近 100 条启用/默认变更可查，普通草稿创建和保存记入标准审计。

## 历史真实性

- 自定义版本码为 `cr-{id}`，基础版仍为 `four-dim-v1`。已启用版本不允许原地编辑。
- 新提交保存 `rubric_snapshot_json`，包括版本码、标题、说明、算法标识和 11 项指标内容。
- 历史基础版若早于快照功能，只返回已知固定指标与计算规则，并标记 `BUILTIN_LEGACY`、`legacy:true`；**不会追溯编造当时的锚点**。
- 无法识别的旧版本或损坏、不匹配的快照报错，不能以当前默认量规冒充；评分也拒绝该损坏记录。
- 复评只增加评价修订，不新增提交版本，也不更换原提交量规。重复提交请求的幂等重试不重新生成快照。
- 从阅读/评分入口进入「课程量规」显示绑定快照。需要查看当前配置时，须显式选择课程版本。

## 权限和输入保护

- 教师可创建、编辑、启用、切换默认、读处理记录；学生和助教只读已启用内容。
- 所有入口校验当前课程成员与教师身份；跨课程量规引用被拒绝。写入要求 CSRF，拒绝未知字段与权重等越权输入。
- 保存草稿使用量规修订号，启用/默认切换另校验课程目录修订号；过期窗口不会静默覆盖。
- 冲突可「刷新并保留当前输入」，显式比较服务器内容后再保存。若他窗已启用，旧输入不能覆盖，只能先放弃，再复制新草稿。
- 未提交的启用/切换理由离开前要求明确确认；未保存量规正文阻止页面导航；本机备份按账号、课程、版本隔离。保存失败/刷新后提供明确的恢复入口，不自动覆盖服务器。
- 会话过期时保存备份；本机存储不可用则提供 JSON 下载，并阻止直接重新登录丢失内存输入。共享设备须清理站点数据。
- 本轮没有量规草稿删除、跨课共享、导入导出工作流或生产多教师协同审批。

## 存储与 API

Flyway `V10__versioned_course_rubrics.sql`：新增 `course_rubric`、`rubric_event`，课程默认量规/目录修订号，作业绑定 id，提交量规快照。不回填伪造旧提交快照。

| 路由（前缀 `/api/courses/{cid}/rubrics`） | 用途 |
|---|---|
| `GET /` | 当前成员可见目录、默认版本及目录修订号 |
| `GET /{code}` | 已启用版本，或教师自己的课程草稿 |
| `POST /` | 从已启用版本复制草稿；`sourceId` 可为 0 |
| `PUT /{id}` | 保存草稿，附 `revision` |
| `POST /{id}/enable` | 冻结并设默认，附 `revision/catalogRevision/reason` |
| `PUT /default` | 切换新作业默认，附 `rubricId/catalogRevision/reason` |
| `GET /history` | 仅教师：最近启用、默认切换记录 |

创建作业请求可附 `rubricId`；0 为基础版，正数必须是本课程已启用版本，省略则在课程行锁内解析当时默认值。现有客户端仍可省略。

## 本地验收运行

先构建前端并复制到后端静态资源，然后 `mvn verify`（JDK 21）。浏览器专项通过 `npm run test:rubrics --prefix frontend` 启动；必须设置 `E2E_BASE_URL=http://127.0.0.1:<独立端口>` 和 `E2E_PASSWORD`，脚本拒绝非 loopback 地址。请使用全新、独立数据库，不可连接在线服务或真实课程数据。

后端测试直接验证旧提交 NULL 快照、不认识的版本、损坏快照、复评及幂等重试。浏览器专项大部分使用真实 HTTP/数据库流程；旧版缺失锚点的单一 UI 渲染用例显式模拟历史响应，读取失败与离线故障也由路由注入，不把它们冒充真实历史数据库样本。
