# 知识创作工作台（PC）

## 工作区

按用户提供的三栏图文工作台参考重做，不是普通富文本表单的换色。

- 左栏：只展示标题章节的分级目录、当前章节定位、已挂证据 E1…、当前作业与截止时间。
- 中栏：连贯的白色图文画布、标题、完整常用工具栏、自动保存/版本记录/提交评审。大纲与右栏可独立收起。
- 右栏：真实提交版本的质量环、四维指标条、教师批注与回应、历史版本。明确显示分数不是当前草稿的实时分数。
- 教师评审与社区阅读共用同一套正文节点。四维 11 项计分不改成参考图的五维，所有正式评分仍由教师发布。

## 内容编辑

- Markdown 快捷输入、`/` 菜单、选中文字浮动工具、撤销重做、链接、证据、正文 `.md` 导出继续可用。
- 图片：PNG/JPEG 文件上传、从剪贴板粘贴图片文件、拖入图片文件；编辑替代文本、图注和来源；换图、删除（可撤销）、为图挂证据。
- 表格：插入 3×3 表格，直接填写、Tab 切换单元格、加行/列、删除行/列或整表；最多 50 行、12 列。不提供单元格合并操作。
- 公式：LaTeX 输入、KaTeX 预览与只读排版；安全选项 `trust:false`，限制展开和尺寸。不抓取外部资源或执行脚本。不是手写识别或公式计算器。
- 提示块：强调核心结论与误区，与普通引用区分。
- 删除带证据的段落/图片后，不静默删除证据；提示用户撤销或移除失效关联，避免产生无法定位的证据。

## 数据、安全与兼容性

- 正文仍为 TipTap JSON；段落、标题、新代码块、图片、公式使用稳定 blockId。旧代码块仍兼容无 ID。格式切换保留段落 ID。
- 图片使用 V2 Flyway 迁移新增的 `entry_media` 数据表，开发阶段存数据库二进制；**不是对象存储**。
- 上传仅限作者；需登录、课程权限及 CSRF。按实际文件内容解码、验证并重编码，不信任扩展名/MIME。不接受 SVG、GIF、WebP、HTML 或远程图片抓取。
- 单文件输入 ≤5MB，单边 ≤6000px、总像素 ≤1600 万，重编码输出 ≤8MB；每篇最多保留 60 个媒体资产（包括历史和取消插入后已上传的资产）。目前没有自动回收/生产级配额管理。
- 图片 URL 为 `/api/media/UUID`；保存正文时校验其属于当前作品。返回 `private, no-store`。
- 作者和本课教师/助教可读；同课其他学生只能读取**当前已获批指定版本实际引用**的图片。撤回后不可继续读取；新草稿图片不会因旧版已经发布而被公开。
- 换图创建新资产，不覆盖历史媒体；旧版正文与媒体 URL 均保持不变。图片内容变更在现有比较器中显示为结构/格式变化；这不是图像视觉 diff。
- `.md` 包含标题、正文、表格、公式与图片站内引用；**不打包图片二进制、批注、评分、证据或历史版本**。站内图片链接离开登录环境后可能不可用，不能将导出视为完整课程备份。
- 不支持整篇 Markdown 导入、源码编辑、代码语法高亮、实时协作或自动教材核验。本期仅 PC（1280px 以上）。

## 平台推进

- 新增学生「学习轨迹」与教师/助教「教学进展」：按权限读取作品、真实提交版本、每篇最近已评分质量、四维分数及反馈处理情况。
- 未评分显示待评审，不当作零分；均分取每篇最近一次有正式评分的版本，不把跨作业差异说成成长幅度。
- 社区卡片可显示获批版本的真实图片封面，支持最近发布/质量分排序，仍遵守指定版本发布和课程权限。
- 编辑器按需加载，初始页面主 JS 约 163KB（未 gzip）；编辑器与公式模块仍约 734KB，后续继续优化。

## 可选：独立图文演示作业

`seed-studio-example.mjs` 只用于默认演示课程，必须显式设置 `ALLOW_DEMO_WRITE=true`、`DEMO_BASE_URL`、`E2E_PASSWORD`。它通过真实 API 新建明确标注的「新版图文编辑体验 · 演示作业」，使用仓库中的自绘 SVG 生成 PNG，保存并提交独立示例作品，写入明确注明“功能演示、非真实学习评价”的评分/批注与发布记录。不覆盖原有作业或草稿；检测到示例已有提交时保持其草稿不变。不要对真实课程运行。

`capture-studio-demo.mjs` 可在本机隔离演示环境截图，只接受 localhost / 127.0.0.1 地址。截图和生成的 PNG 存入忽略的 `.qa/`，不作为应用依赖。

## 可视化公式增量

公式入口现支持六类结构拼装与六个科学模板，可继续编辑 LaTeX；输入方式切换保留本次未应用字段，应用结构后再确认写入。新增选区原文保留、稳定节点 ID、旧位置更新拒绝、长度/命令限制与弹窗键盘焦点循环。详见 `VISUAL-FORMULAS.md`。这是结构化排版，不是求解、配平或完整手写/WYSIWYG 数学系统。
