# Markdown 风格文档编辑器

## 已实现（PC）

这是 TipTap 结构化富文本上的即时排版体验，不是左右双栏源码编辑器。

- 在段落开头输入 `# `、`## `、`### `、`- `、`1. `、`> `、三个反引号加空格和 `--- `，转换为标题、列表、引用、代码块或分隔线；`**文本**`、`*文本*` 和反引号包围文本支持行内格式。
- 输入 `/`，用中英文关键词筛选内容块，↑↓ 选择、Enter 插入、Esc 关闭；也可以点击“插入”。
- 选中文字后显示浮动工具栏：加粗、斜体、删除线、行内代码、链接、为选中段落挂载证据。
- 正文内 Ctrl / ⌘ K 设置链接，不触发全局搜索。只接受完整 http / https 地址；普通链接不等同于已经核验的证据。
- 安静的文档画布、760px 编辑正文宽度、标题层级、引用与代码样式、字符数及估算阅读时长。大纲和反馈栏仍可按需收起。
- 支持撤销重做、原有自动保存与冲突处理，以及导出正文 Markdown。

## 数据与兼容性

正文仍保存为 TipTap JSON。段落、标题和新代码块有稳定标识；格式转换、证据、教师反馈与版本差异仍基于标识关联。旧代码块允许没有标识，避免升级后拒绝保存历史正文。后端同时校验新文字格式和链接，拒绝危险协议、未知格式及重复代码块标识。

导出的 `.md` 只包含标题和正文，**不包含批注、证据附件、评分或版本记录**，不能作为课程完整备份。暂不支持整篇 Markdown 导入、源码模式、表格、图片上传、数学公式或代码语法高亮。本期只做 PC。

## 本次验证

- Vue / TypeScript 生产构建通过；后端 25 项测试通过（新增 5 项正文与链接校验）。
- Markdown 导出序列化：7 项断言通过。
- `scripts/writer-e2e.mjs`：17 项检查、8 个界面状态；实际验证格式转换保留旧段落 ID、快捷语法、菜单、浮动工具、撤销重做、链接快捷键、证据段落、保存重载、冻结旧版本和 Markdown 下载。
- 原有 UI 19 个页面/状态及 HTTP 29 项业务断言再次通过，包括真实提交 v2 与教师评审队列。
- Chromium，1440px / 1280px PC 与深色；未发现页面脚本错误或页面横向溢出。演示数据库与真实课程隔离。

复验需要 Node 24、Playwright 和已初始化的独立演示库：

```bash
node scripts/markdown-test.mjs
# 使用初始化演示库时设置的 E2E_PASSWORD；不可指向真实课程。
E2E_BASE_URL=http://127.0.0.1:8084 node scripts/writer-e2e.mjs
```

写作脚本会修改默认演示作品；需在新初始化的演示库运行。原有 UI 脚本可在写作脚本之后运行，提交其修订版。
