## 本轮发现并处理

1. 登录认证成功后，原实现过早显示工作区导航，课程初始化完成又跳回首页。现在初始化完成前保持加载态；失败回到可重试登录，不暴露半加载工作区。新增延迟课程请求和初始化失败重试两组回归。富文本专项中教师立即导航问题随之解决，没有用延时掩盖。
2. 作业专项的旧选择器同时匹配新增量规快照与嵌套指标，导致严格定位失败。改为精确选择“提交时的任务规则”顶层 summary，保留历史任务与后续规则不相混淆的断言；不削弱业务检查。
3. 源码恢复前核对上次清单的 **153 项 SHA-256 全部匹配**，保留原全部文件；新归档逐文件重新核验。
4. 构建清理旧静态资源；配置预检拒绝危险本地配置；H2 备份验证真实 Java 文件锁拒绝在线复制、不覆盖恢复、原有账号/课程/提交/评价/私有草稿/反馈/发布记录及图片字节一致。

## 不能由本验收推出的结论

- 不是生产安全审计、合规认证、MySQL 容灾、200 会话压力测试或所有浏览器/全移动端认证。
- 演示数据的评分/审核用于测状态机，不证明实际学术结论或学生学习成效。
- 备份 SHA-256 不是签名；备份不是加密文件。只在停机、可信来源、新目标路径下使用。
- 七类后续能力仍未实现，见 `COMPLETION-STATUS.md`。当前版本四项收尾完成不等于全部长期建设完成。
