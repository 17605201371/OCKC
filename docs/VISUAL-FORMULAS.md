# 可视化公式输入（本地增量）

本轮只完善 PC 写作工作台，不连接 AI、不调用外部公式服务、不部署上线。现有公式节点仍保存标准 LaTeX 和稳定 blockId，不更改正文数据结构或数据库迁移。

## 使用

1. 在普通正文选择位置，点击“公式”或 `/` 菜单中的公式。
2. 可继续使用 **LaTeX 输入**；也可切到 **可视化输入**，选择分式、上标/幂、下标、平方根、等式或化学反应式。
3. 结构字段支持字母、数字、常用希腊字母与基本运算符；填写后即时预览。点击“应用结构到公式”生成 LaTeX，再点击“确认公式”写入正文。在结构模式下不能跳过应用直接写入，避免提交旧的隐藏输入。
4. 原有 LaTeX 输入不会因切换输入方式被覆盖；视觉结构的填写状态在本次对话框内保留。复杂嵌套可应用结构后继续编辑 LaTeX。
5. 常用模板包括 ATP 转化、质能关系、分式、光合作用总式、一元二次求根、算术平均；替换已有公式输入须确认。
6. 反应式将化学式中的数字转为下标，保留前面的系数，可选单向/可逆箭头。

## 防误操作

- 选中文字后插入公式，插在所选范围之后，不会悄悄删除原文字。
- 编辑现有公式保留 blockId；公式关联引用位置不因改变 LaTeX 而更换。
- 打开对话框时记录正文快照、编辑器实例、作品和原公式位置。若正文或可写状态已改变，拒绝旧位置提交并要求重新核对，不把公式插入其他作品或覆盖新正文。
- 空公式、语法错误、超过 2000 字符、控制字符、外链/HTML/资源加载及自定义宏命令不能写入。KaTeX 同时保持 trust=false、有限展开次数与尺寸。
- 取消/Escape 不改变正文，关闭后回到编辑器。原生 dialog 约束键盘焦点；浅色/暗色使用主题变量。390px 验收仅针对该对话框，不代表整个应用已完成移动端适配。
- 保存/重载、Markdown 导出和不可变提交继续使用同一 LaTeX 数据；阅读模式没有公式编辑操作。

## 边界

这是可视化**结构拼装与符号排版**，不是数学求解器、手写识别、全 WYSIWYG 数学编辑器或学科正确性验证。反应式不自动配平，不处理全部电荷/同位素语法；高级内容可用 KaTeX 支持的 LaTeX。模板示例也不构成证据来源或评分依据。暂不接受视觉结构字段中的任意 LaTeX 命令，避免字段内容改变公式外层结构。

验证：`npm run test:formula:unit`，`node scripts/qa-local.mjs --isolated-local --suites formula`（先构建）。统一验证入口也已加入公式单元检查。最终实际结果见本轮验证文档，历史测试记录不冒充重跑结果。
