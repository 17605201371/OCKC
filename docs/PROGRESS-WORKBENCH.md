# 学习轨迹与教学进展

按真实作品聚合提交、当前生效教师评分、历史反馈和证据状态。学生只能查看本人轨迹；教师和助教可只读查看本课程轨迹，助教不因此获得教师私有评分草稿。

列表每页 20 个作品，卡片最多显示 5 次最近提交；完整版本与历史反馈分别在原生模态框中服务端分页。教师按作业、作者、关键词、状态和排序筛选。

概览统计遵循作业/作者/关键词作用域，不随状态标签和分页改变。质量均分取每篇作品最近已评分版本，不把未评分当零、不以修订次数推断成长。回应、采纳或忽略不等于解决，仍需教师确认。反馈跳转定位原提交版本的原段落，不替换为最新草稿。

ProgressWorkbenchTest 20 项覆盖权限、统计口径、分页、反馈解决状态和查询边界。基础报告导出已在后续本地迭代实现，见 `PROGRESS-REPORTS.md`；性能优化和班级深度分析另行推进。
