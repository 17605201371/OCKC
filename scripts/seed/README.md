# 演示数据生成与审计脚本

给演示环境造数据、跑接口与界面审计用的工具，不是应用运行时依赖。

| 文件 | 用途 |
| --- | --- |
| `seed_lib.py` | 登录、发请求、建草稿的公共函数，被其余脚本复用 |
| `seed.py` / `seed_long.py` | 建作业 → 提交 → 批注 → 发布 → 评价的完整演示链路 |
| `figs.py` / `figs2.py` | 用无头 Chrome 把 HTML+SVG 截成配图，产物在 `figs/` |
| `audit_*.py` / `probe_*.py` / `verify*.py` | 接口与页面审计，只读不写 |

## 运行前提

脚本默认指向演示环境 `http://47.105.100.205:8080`，登录密码与 `DemoSeed` 的种子账号一致。
密码目前以明文写在各脚本里；如果这个仓库要转为公开，先把它们换成
`os.environ["DEMO_PASSWORD"]` 再推。

## 与线上数据的关系

`seed.py` 会往库里写作业、提交、批注与发布记录。跑之前先备份
`/opt/ockc/data/community.mv.db`，跑完核对演示数据条数是否符合预期。
